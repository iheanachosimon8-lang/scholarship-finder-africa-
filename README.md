# Scholarship Finder Africa

**Find opportunities. Fund your future.**

A student-first platform beginning with Nigerian students, with plans to expand across Africa.

## Current stage
Stage 1 foundation and first responsive website preview.

## Planned features
- Searchable scholarship and funding opportunity directory
- Clear eligibility, benefit and deadline information
- Official application links and source verification
- Student accounts and saved opportunities
- Deadline and email alerts
- Application guides
- Admin dashboard for managing listings

## Important information
The initial programme cards are starter profiles, not confirmation that applications are currently open. Always confirm current eligibility, deadlines and application instructions on the official provider website. Listings will only be labelled verified after the source and details have been checked.

## Technology
Initial version: HTML, CSS and JavaScript. Planned hosting: Vercel. Planned database and authentication: Supabase.
